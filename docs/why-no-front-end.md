# Why no front end

A manager can review measurements, overdue cleaning, held deliveries and training evidence by asking an agent to run the CLI. HTML views and inspection packs are read-only documents that can be printed. That is the scope of this base.

A screen gives kitchen staff quick phone entry, offline recording, camera capture and live alerts. This base has none of those, no sensor connection and no drag and drop. Staff must record actual observations through an agreed process. Enterprise DNA scopes a phone interface or device connection when it is needed. Do not replace a capture process until the team has a working replacement.

The database is the product. Claude Code, Codex, OpenCode and Cursor are interchangeable doors. There is one source tree and one set of commands. PGlite is useful for one operator on a laptop; a managed Postgres installation needs access controls, backups and an evidence archive before a team uses it.
